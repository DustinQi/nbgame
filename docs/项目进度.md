## 下一步计划：投掷武器 + 靶子

> 这是原型的第一个玩法里程碑：让玩家能扔东西、能把靶子打倒。

| 要做的东西 | 说明 |
|------------|------|
| 武器数据 | 定义「筷子」的伤害、飞行速度、冷却时间 |
| 投掷物 | 按鼠标左键飞出筷子，有重力会下坠，撞到靶子或墙会结算伤害 |
| 武器管理器 | 管理当前武器和冷却，防止狂点鼠标无限扔 |
| 靶子假人 | 有 60 点血，被筷子打中掉血，血空后消失 |

**做完后您怎么验收**：运行 `game/run.sh`，用鼠标瞄准靶子、按左键扔筷子，能看到靶子掉血、血空后消失。

详细实现步骤见 `docs/superpowers/plans/2026-10-18-jiayue-cloud-godot-plan.md` 的 Task 4、Task 5、Task 7。
