# 技能选择指南

> 本文件是 CLAUDE.md 的外链细则，列出**各类开发场景对应的 Skill 选择**。
> 触发条件：需要选择合适的技能/工具来完成任务时。
>
> 注：技能名保持英文形式（原始命名），王总可用中文触发调用（见 `自然语言命令映射.md`）。

---

## 规划与设计

| 场景 | 可选 Skills | 说明 |
|------|------------|------|
| 功能规划 | `superpowers:writing-plans` | 制定实施计划 |
| 系统架构 | 直接分析（无需专门技能） | 架构决策和设计，先分析再动工 |
| 需求梳理 | `superpowers:brainstorming` | 和王总一起探索需求 |

## 开发与实现

| 场景 | 可选 Skills | 说明 |
|------|------------|------|
| 分步开发 | `superpowers:subagent-driven-development` | 复杂功能拆解实现 |
| 并行任务 | `superpowers:dispatching-parallel-agents` | 多任务同时推进 |
| 重构清理 | 直接整理（不改变已有功能） | 代码清理和重复消除 |

## 质量保障

| 场景 | 可选 Skills | 说明 |
|------|------------|------|
| 代码审查 | `superpowers:requesting-code-review` / 直接逐文件审查 | 提交前审查 |
| 安全审查 | 按安全习惯自查 | 无硬编码密钥、输入验证、错误不泄露敏感信息 |
| 隐蔽 Bug | `superpowers:systematic-debugging` | 排查沉默错误 |
| 性能优化 | 直接分析优化 | 先找瓶颈再动手，别提前优化 |
| 构建修复 | 直接排查 | 编译错误逐条修复，改完验证 |
| 最终验证 | `superpowers:verification-before-completion` / `verification-loop` | 完成前确认 |

| 发求助邮件 | 直接起草邮件正文 | 收件人 dustinqi0452@gmail.com，由王总自己发送 |

## 自动遵循的规则体系

以下规范写在 CLAUDE.md 和项目文档里，开发时自动生效，无需手动调用：

- **编码风格** — CLAUDE.md「代码规范快查」：PascalCase/camelCase/`_` 前缀、方法 ≤50 行、中文注释
- **Git 提交** — `项目约定.md`：`<type>: <描述>` 格式
- **开发流程** — `开发工作流.md` 七步流程
- **安全习惯** — `沟通规则.md`：不硬编码密钥、用户输入验证、错误不泄露敏感信息
