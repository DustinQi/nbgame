# 嘉悦云上 — 游戏设计文档

> 创建日期：2026-08-02
> 状态：设计阶段，待实现

---

## 一、游戏概述

**一句话描述：** 第一人称投掷武器 + 超能力，在「嘉悦云上」小区中爽快清版闯关，夺回被开发商占领的家园。

**游戏类型：** 第一人称动作清版（First-Person Arena Clear），单人剧情闯关

**目标平台：** Steam（PC），使用 Unity 2022.3.62f3c1 LTS 开发

**参考风格：** DOOM（战斗节奏）+ 投掷武器独特性 + 都市奇幻世界观

### 核心差异点

传统 FPS 用枪，本作用投掷武器：
- 武器全部是日常生活用品，随手捡来就能战斗，合情合理又好笑
- 每次出手一发，投出后需回收或等冷却
- 弹道有飞行时间，需要预判
- 回收机制（走捡/念力召回）鼓励移动
- 投掷比枪械更有"手感"，每次击杀都有分量

## 二、故事与世界观

### 背景

近未来的亚洲某城市。名为「嘉悦云上」的高端小区刚刚交房，业主们满怀期待准备入住。

地产开发商联合小区业主中的不良分子，武装占领了整个小区。大门封锁、楼栋被占、公共区域变成了他们的据点。普通业主被拒之门外，有家不能回。

主角是一个普通业主，也是小区业主群里最活跃的人。在混乱中，广大业主推举其为带头人。「觉醒」事件激活了主角的超能力——现在，要用手里的投掷武器，把小区一栋一栋夺回来。

### 敌人势力

| 势力 | 身份 | 特点 |
|------|------|------|
| 基础小怪 | 开发商打手 | 穿黑西装的壮汉，持棍棒、砍刀、简易盾牌。数量多但脆，一筷子一个 |
| 精英小怪 | 不良业主 | 站错队的业主，装备更好，会躲会包抄，比打手聪明 |
| 关底 Boss | 邪恶业主头目 | 每栋楼一个，各怀绝技，打法各异 |
| 最终 Boss | 「西子」 | 甩动双乳喷射毒奶作为武器，毒奶范围大、持续伤害、地面留毒池限制走位 |

### 叙事方式

环境叙事为主，不做大段对话和播片：
- 每栋楼的场景风格不同（被改成赌场的会所、堆满物资的地下车库、被涂鸦覆盖的儿童乐园）
- 业主群聊记录散落在场景里
- 每清完一栋楼，无线电收到业主感谢
- Boss 战前三言两语的交锋

主线：一栋一栋打过去，把「嘉悦云上」夺回来。

## 三、核心战斗机制

### 投掷武器系统

多种投掷武器，全部是日常生活中常见的食品和日用品，快速切换，每种手感不同：

**快攻型（精准、出手快、冷却短）：**

| 武器 | 来源 | 特点 |
|------|------|------|
| 🥢 筷子 | 厨房 | 飞镖一样直线扎过去，爆头神器 |
| 🔧 螺丝刀 | 工具箱 | 比筷子重，伤害更高，主力投掷物 |

**散射型（一次扔多个、扇形散布）：**

| 武器 | 来源 | 特点 |
|------|------|------|
| 🀄 麻将牌 | 会所麻将桌 | 一把撒出去，扇面覆盖，清群怪 |
| 💿 光盘 | 书房 | 像飞盘一样旋转飞出，扫一片 |

**重击型（出手慢、伤害高、打出硬直）：**

| 武器 | 来源 | 特点 |
|------|------|------|
| 🍳 平底锅 | 厨房 | 抡一圈扔出去，砸中直接拍飞 |
| 🔨 羊角锤 | 工具箱 | 最重的投掷物，命中直接倒地 |

**特殊型（奇奇怪怪的花活）：**

| 武器 | 来源 | 特点 |
|------|------|------|
| 🍺 啤酒瓶 | 冰箱/酒柜 | 扔出去碎一地，范围伤害 + 玻璃渣减速 |
| 🩴 拖鞋 | 玄关 | 扔出去自己飞回来，不用回收，伤害低 |
| 🧨 鞭炮 | 储藏室 | 点着延迟爆炸，AOE 伤害 + 音效带感 |
| 🌶️ 辣椒粉 | 厨房调料架 | 扔脸上一团红雾，致盲敌人几秒 |

**回收机制：** 投出的武器嵌在敌人或场景上，两种回收方式：
1. 走过去捡（自动回收）
2. 念力召回——消耗能量，所有武器飞回手中，路径上碰到敌人也受伤

回收机制让玩家时刻关注"弹药"，也鼓励不断移动。

### 超能力系统

消耗能量，杀敌补充。用来强化投掷，不是替代投掷：

| 能力 | 效果 |
|------|------|
| 时间减速 | 瞄准时短暂慢动作，方便爆头 |
| 武器附魔 | 给下一发投掷附加火焰/雷电/冰霜效果 |
| 念力召回 | 隔空回收所有武器，路径上造成伤害 |
| 冲击波 | 推开周围敌人，紧急脱身 |
| 闪现冲刺 | 快速位移，躲技能、抢位置 |

### 战斗循环

```
瞄准投掷 → 杀敌 → 能量积满 → 放技能 → 召回武器 → 换目标 → 继续投掷
```

没有换弹、没有躲掩体回血。杀敌掉血包和能量。越猛越强。

## 四、关卡与进度

### 关卡结构

每关一段城市场景，分多个战斗区域，中间用过场连接：

```
关卡开始 → 战斗区1 → 清场 → 通道 → 战斗区2 → 清场 → ... → Boss战 → 关卡结束
```

**区域类型：**
- 标准战斗区：封闭空间，敌人多方向涌来
- 垂直战斗区：多层建筑，上下穿梭
- 开阔广场：大范围 + 大量敌人，考验远程瞄准
- 走廊遭遇：狭窄空间，近距离拼反应

### 能力成长

成长体现在获得新武器和新超能力，不是等级和装备数值：

- 新武器通过剧情获得（银河城式解锁），不是购买或掉落
- 新超能力每过一个 Boss 获得
- 武器和技能可用关卡收集的资源升级（伤害、冷却、数量）

### 目标规模

作为首次开发，建议规模：

| 项目 | 数量 |
|------|------|
| 关卡数 | 5-7 个 |
| 投掷武器 | 10 种（四类） |
| 超能力 | 5 种 |
| Boss 战 | 3-4 场 |
| 总时长 | 2-3 小时 |

## 五、技术方案

### 开发环境

- Unity 2022.3.62f3c1 LTS
- C# 脚本
- 目标平台：macOS 开发 → Steam (Windows/Mac) 发布

### 核心系统

| 系统 | 说明 |
|------|------|
| 角色控制器 | 第一人称移动、跳跃、闪避 |
| 投掷系统 | 瞄准弹道、飞行轨迹、命中检测、回收逻辑 |
| 超能力系统 | 技能冷却、能量管理、技能效果 |
| 敌人 AI | 巡逻、发现玩家、战斗、逃跑 |
| 关卡管理 | 战斗区域触发、清场判定、开门解锁 |
| UI 系统 | 准星、武器栏、血量能量条、Boss 血条 |

### 开发顺序

1. 角色控制器（移动 + 视角）
2. 投掷系统（瞄准 + 弹道 + 命中 + 回收）
3. 超能力系统（能量 + 技能）
4. 敌人 AI + 基础小怪
5. 关卡管理 + 第一个可玩关卡
6. 精英怪 + Boss 战
7. 全部关卡 + 打磨

## 六、错误处理与测试

### 错误处理原则

- 所有玩家输入需要边界检查（空引用、越界）
- 场景切换时确保对象正确加载/卸载，防止内存泄漏
- 敌人 AI 状态机必须有兜底行为，防止卡住
- 投掷物回收必须有保底超时自动回收

### 测试策略

1. **单元测试**：工具类、数据计算逻辑（伤害公式、冷却时间等）
2. **集成测试**：投掷系统与敌人交互、超能力与武器配合
3. **手动测试**：关卡体验由王总在 Unity Editor 中直接测试，截图反馈异常
